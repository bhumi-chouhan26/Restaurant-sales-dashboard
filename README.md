## Project Description

A console-based Python program that reads `restaurant_sales.csv` using Pandas, calculates Sales (Quantity x Price), and shows sales by category, by date, and the top item by quantity and by revenue. It also creates charts (saved as `dashboard.png`). Invalid rows are skipped with a warning, and a missing file is handled with an error message.

## Concepts Used

- Pandas (DataFrame, GroupBy)
- Matplotlib (charts)
- CSV file handling
- Exception handling
- Functions and menu-driven program

## Files

| File | Description |
|------|-------------|
| `RestaurantSalesDashboard.py` | Main program |
| `restaurant_sales.csv` | Sample sales data |
| `dashboard.png` | Charts generated by the program |

## How to Run

1. Install the libraries: `pip install pandas matplotlib`
2. Keep `RestaurantSalesDashboard.py` and `restaurant_sales.csv` in the same folder.
3. Run: `python RestaurantSalesDashboard.py`
4. Enter the file name `restaurant_sales.csv` and choose an option from the menu.

## Menu

1. Sales by category
2. Top items
3. Daily sales
4. Top items and daily sales
5. Show charts
6. Exit
